# UDP Ping 架构设计

## 概述

UDP Ping 是一个用于测试 UDP 连接质量的工具，采用客户端-服务端架构。

## 架构图

```
┌─────────────────┐         UDP Probe Packets        ┌─────────────────┐
│                 │ ─────────────────────────────────>│                 │
│  UDP Ping       │                                   │  UDP Ping       │
│  Client         │                                   │  Server         │
│                 │<───────────────────────────────── │                 │
└─────────────────┘      UDP Feedback Packets        └─────────────────┘
```

## 核心组件

### 1. 协议层 (pkg/protocol)

负责定义和处理 UDP Ping 的数据包格式。

**主要功能：**
- 定义数据包结构
- 序列化/反序列化
- 包类型定义

**数据包格式：**
```
+--------+----------+-----------+
|  Type  | Sequence | Timestamp |
| 1 byte | 8 bytes  | 8 bytes   |
+--------+----------+-----------+
```

### 2. 统计层 (pkg/stats)

提供统计功能，跟踪发送、接收和丢包情况。

**主要功能：**
- 计数器管理（发送/接收）
- 丢包率计算
- 统计报告生成
- 线程安全操作

### 3. 服务端 (cmd/udpping-server)

监听 UDP 端口，接收客户端探测报文，并定期发送反馈。

**主要流程：**
1. 创建 UDP 监听套接字
2. 接收探测报文
3. 更新统计信息
4. 定期发送反馈报文
5. 显示统计报告

### 4. 客户端 (cmd/udpping-client)

按照指定频率向服务端发送探测报文。

**主要流程：**
1. 连接到服务端
2. 定时发送探测报文
3. 接收反馈报文
4. 显示统计信息

## 工作流程

### 探测流程

1. 客户端按照配置的频率（如每秒）生成探测报文
2. 探测报文包含序列号和时间戳
3. 客户端通过 UDP 发送报文到服务端
4. 服务端接收报文并更新统计信息

### 反馈流程

1. 服务端定期（如每 10 秒）生成反馈报文
2. 反馈报文发送给所有已知的客户端
3. 客户端接收反馈并显示统计信息

## 并发设计

### 服务端
- 主 goroutine：接收和处理探测报文
- 统计 goroutine：定期生成和显示统计报告
- 信号处理 goroutine：处理程序退出

### 客户端
- 主 goroutine：定时发送探测报文
- 接收 goroutine：接收和处理反馈报文
- 信号处理 goroutine：处理程序退出

## 错误处理

- 网络错误：记录日志，继续运行
- 包解析错误：记录日志，丢弃报文
- 超时：使用合理的超时设置避免阻塞

## 扩展性

### 可扩展点
1. 支持更多统计指标（延迟、抖动等）
2. 支持配置文件
3. 支持多个客户端的独立统计
4. 支持数据持久化和可视化
5. 支持加密和认证

## 性能考虑

- 使用缓冲区池减少内存分配
- 避免不必要的日志输出
- 使用合适的报文发送频率
- 统计数据使用读写锁保护
